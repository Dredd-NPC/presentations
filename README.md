## Структура файлов

- `*.html` — самодостаточные интерактивные файлы (Chart.js через CDN)
- `*_files/` — локальные ресурсы для презентаций, сохранённых из Claude artifacts (CSS, шрифты)

## Соглашения

- Десятичные числа — через запятую (русский стандарт)
- Английские аббревиатуры (LIOB, MMP, TIMP, MLA и т.д.) сохраняются с tooltip-пояснениями на русском
- Все научные данные — только из рецензируемых источников PubMed / PMC OA
- Реальные изображения встраиваются по прямым CDN-URL только из PMC Open Access (с указанием авторства и лицензии)

## Навигация внутри презентаций

- `→` `←` или `Space` — следующий / предыдущий слайд
- `Home` / `End` — в начало / в конец
- Колесо мыши и свайп — навигация на тач-экранах
- `#s12` в URL — deep-link к конкретному слайду
